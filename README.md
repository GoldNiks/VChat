# VChat

Forge 1.20.1 мод: глобальный/локальный чат с префиксами, кастомный таб, логирование команд в консоль.

## Возможности

- **Глобальный чат** — `/g <текст>` или `!<текст>` в чате, видят все игроки
- **Локальный чат** — обычное сообщение, радиус 100 блоков
- **Префиксы** — автоматически подставляются в ник через scoreboard team
- **Кастомный таб** — заголовок, футер и количество игроков
- **Приветствие** — личное сообщение при входе на сервер
- **Логирование** — все команды и чат пишутся в `[VChat]` в консоли
- **Конфиг** — `config/vchat-tab.json` (Forge не трогает, не сбрасывается)

## Команды

- `/g <сообщение>` — глобальный чат
- `/vchat reload` — перечитать конфиг таба
- `/vchat status` — показать текущие header/footer

## Конфиг `config/vchat-tab.json`

```json
{
  "header": "\n&6&l&nVChat\n\n&7Игроки: &a%online%\n\n&7&m-----------------",
  "footer": "&7&m-----------------\n\n&7Баланс: &e0",
  "joinMessage": "&aДобро пожаловать на &6&l&nVChat&a!"
}
```

- `%online%` и `%max%` подставляются автоматически
- `&` для цветов Minecraft, `\n` для новой строки

## Установка

1. Скачать `VChat-1.0.0.jar` из [релизов](https://github.com/GoldNiks/VChat/releases)
2. Положить в `mods/` на сервере
3. Перезапустить сервер
